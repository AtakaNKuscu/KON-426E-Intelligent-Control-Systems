# Harici ders bağımlılığı

`hw2_part1.m`, ders kapsamında sağlanan MATLAB P-code dosyası `System1.p` ile çalışır. Dosyayı bu klasöre yerleştirin ve repo kökünden `setup_course('hw2')` çağırın.

Bu klasördeki harici dosyalar `.gitignore` ile Git dışında tutulur. Yerel taşıma sırasında mevcut `System1.p` kopyalanmıştır; GitHub'dan yeni klonlayan kişinin dosyayı ders kaynağından edinmesi gerekir.
